# Netflix Exploratory Data Analysis (EDA) 📊

This project focuses on performing **Exploratory Data Analysis (EDA)** on the Netflix dataset using Python.
The aim is to understand Netflix’s content distribution, trends, and patterns across different attributes
such as content type, genres, countries, and release years.


## Project Live Preview:
https://ujjwallmishra01.github.io/netflix-eda/

---

## 📂 Dataset Information

- **File name:** `netflix1.csv`
- **Source:** Netflix Movies and TV Shows dataset
- **Description:**  
  The dataset contains information about movies and TV shows available on Netflix, including:
  - Type (Movie / TV Show)
  - Title
  - Director & Cast
  - Country
  - Release Year
  - Rating
  - Duration
  - Listed Genres
  - Date Added

---

## 🧹 Data Cleaning & Preprocessing

The following steps were performed to prepare the data for analysis:

- Removed duplicate records
- Handled missing values in key columns
- Converted date columns to proper datetime format
- Cleaned and standardized categorical values
- Checked and treated outliers where required

These steps ensured the dataset was **clean, consistent, and analysis-ready**.

---

## 🔍 Exploratory Data Analysis (EDA)

The analysis includes:

### 📌 Univariate Analysis
- Distribution of movies vs TV shows
- Count of content by ratings
- Release year trends
- Duration analysis for movies and TV shows

### 📌 Categorical Analysis
- Most common genres on Netflix
- Country-wise content distribution
- Content added over the years
- Relationship between content type and ratings

### 📌 Visualizations
- Bar charts
- Count plots
- Histograms
- Box plots

These visualizations help uncover meaningful patterns and trends in Netflix content.

---

## 💡 Key Insights

Some key observations from the analysis:

- Netflix has a significantly higher number of **movies** compared to TV shows
- Content addition increased rapidly after 2015
- Certain genres dominate Netflix’s catalog
- The United States contributes the largest share of content
- Movie durations are more varied compared to TV shows
